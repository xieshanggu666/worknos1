# 🏠 智居 · 智能家居场景联动与设备健康看板

基于 **Vue 3 + Vite + Pinia（前端）+ Express + SQLite（后端）** 的智能家居演示看板。纯 mock 设备数据，无真实硬件接入。

## 技术栈

- 前端：Vue 3 + Vite + Pinia
- 后端：Node.js 内置 `node:sqlite` + Express，REST API
- 数据库：`server/home.db`（SQLite，首次启动自动建表 + 预置演示数据）

## 运行

```bash
npm install
npm run dev
```

前端 http://localhost:5190（Vite 已代理 `/api` 到 http://localhost:4120）。
需 Node ≥ 22.13。

## 功能

- **健康看板**：设备在线/异常统计、房间分布、设备类型、告警中心（低电量/信号弱/离线/能耗尖峰/检修隔离）、全屋 24h 能耗趋势；告警可一键发起报修，进行中工单实时显示状态
- **设备管理**：按房间/类型/状态筛选，添加/删除设备，开关切换，功率编辑、电量/信号条；隔离中设备锁定开关并显示工单状态
- **报修工单**：住户从告警/设备页发起报修 → 维护人员接单 → 隔离设备并检修（填处理结果）→ 住户确认后恢复控制。隔离期间手动开关、远程改开关、场景联动、删除设备全部被服务端拦截并写日志
- **场景联动**：可视化动作编排（设备→动作），创建/启用停用/触发场景，触发后写入日志并联动开关真实设备状态；动作命中隔离设备时跳过并如实回报失败
- **能耗统计**：按房间分布、设备用电排行、实时功率、节能提示
- **日志时间线**：所有操作的实时记录（含报修流转、隔离锁定/拦截事件，按事件类型着色）

顶部可切换 **🏠 住户 / 🛠️ 维护人员** 视角，看到与当前角色对应的工单操作按钮（选择保存在本地）。

## 报修工单状态机

`pending 待接单 → accepted 已接单 → isolated 隔离检修中 → repaired 待住户确认 → done 已恢复`；`pending/accepted` 阶段住户可撤销（`cancelled`），隔离后不可取消，必须走完检修+确认流程。设备删除后工单以名称快照留档。

## 数据库表

`rooms` `device_types` `devices`（含 `isolated` 隔离标记）`scenes` `scene_actions` `device_logs` `energy` `repair_orders`
